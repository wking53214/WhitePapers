# Consolidated Super-Prompt — SUPERSEDED, DO NOT PASTE

This single-file form was split on 2026-09-16 because pasting it whole into
a fresh session hands every phase agent the RUN-B findings and the C(0)
status, which contaminates the clean run.

Use instead:

- `AGENT-TASK-SPEC.md` — the clean specification agents receive.
- `OPERATOR-BRIEF.md` — operating preferences, RUN-B history, C(0) frozen
  state, source map. Human and orchestrator only; never given to an agent.

The pre-split content is preserved in git history (commit `9085e3f`).
